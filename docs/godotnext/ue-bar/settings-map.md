## NextGI (Lumen)

Hardware ray tracing for a Lumen row means the project settings **Support Hardware Ray Tracing** and **Use Hardware Ray Tracing when available**, both enabled ([Lumen GI, 5.9][lumen59]; the same names as 5.8). The 5.9 page adds that new projects enable Support Hardware Ray Tracing. The [console-variable reference][cvars59] prints `r.Lumen.HardwareRayTracing` with default 0, described as using hardware ray tracing when available and falling back to software otherwise. The comparison enables the two project settings. It does not treat that cvar's default of 0 as "on". Each launch sets the tier with `r.Lumen.HardwareRayTracing`, 1 for hardware ray tracing and 0 for the software tier, and the report checks the echoed value (plan v3.9.7, §23.4).

Two UE 5.9 settings hold for every hardware ray tracing row (**UE 5.9 Preview**):

- **Hardware Ray Tracing Mode** stays at **Full** on Windows. It is in Project Settings > Platforms > Windows, Renderer section, and Linux has the same setting. The [Lumen World Cache page][worldcache59] prints Full as "the default"; on 2026-11-18 that page returned Epic's not-found page, so the link is the Internet Archive's copy of 2026-11-16, and its statements stand until the plan's §25.3 re-check (plan §26.2); the [ray tracing performance guide][rtperf59] lists Disabled, Inline, Simplified Material and Full under Platforms > [Platform]. Inline and Simplified Material remove Lumen hit lighting. The [archived 5.8 guide][wb-rtperf58] called this per-platform setting Ray Tracing Mode, with Disabled, Inline and Full. No page prints the setting's options or default for Mac, so the M5 Max rows do not name it; that observation waits for the M5 Max. GodotNext's side is `nextgi/hardware_ray_tracing_mode = full`, its default (#286, plan §21.1.1).
- **Lumen World Cache** stays off, the UE 5.9 default ([Lumen World Cache][worldcache59]: "The World Cache is off by default."). It turns on only with `r.Lumen.WorldCache.Supported=1` in `DefaultEngine.ini`, applies only when Lumen uses hardware ray tracing, and replaces the Surface Cache while active. Its GPU time is reported as LumenWorldCache in `stat gpu`. The page carries no Experimental or Beta banner. GodotNext's counterpart is the plan's §21.2 World Cache row (#294), off by default and not built yet, so the comparison runs with it off on both sides. The page is withdrawn since 2026-11-18 and these statements rest on its archived copy (plan §26.2).

The Lumen total, where a row names it, is the sum of the three `stat gpu` passes the [performance guide][lumenperf59] prints: **Lumen Scene Lighting**, **Lumen Screen Probe Gather** and **Lumen Reflections**. This is the same as 5.8; with the World Cache off, no fourth pass joins. The guide recommends `r.Lumen.AsyncCompute 0` to measure Lumen on its own; #229 sets it in the comparison's `exec_cmds` (2026-11-15), so the three passes are not timed under async overlap, and the report checks the value each run echoes. On 2026-11-16 the lead confirmed that UE's async compute is off in every timing set (plan v3.9.7, §23.4). The game-mode capture on the RTX 4080 SUPER (2026-11-15) shows no single column for the sum. Until #229 step 2 writes the columns into this record and §23.5, the kitbash comparison config sums the three observed columns `GPU/LumenSceneLighting`, `GPU/LumenScreenProbeGather` and `GPU/LumenReflections`.

**Column groups (plan v3.9.7, lead decision 2026-11-16).** The UE side of a column group includes every pass the game-mode runs report that does the same work as the GodotNext group, not only the passes a public page names. GS-9 (the kitbash set) adds `GPU/LumenSceneUpdate` and `GPU/UpdateLumenSceneBuffers` to the three Lumen passes. G3-5 (Glass & Water) adds `GPU/TranslucentLighting` and `GPU/Translucency` to the Lumen total. GM-2's group is in the MegaLights row under [Shadows, lights and fog](#shadows-lights-and-fog). #229 applies the same rule when it writes the other groups' columns.

- Lumen hardware ray tracing and MegaLights on Apple Silicon M2+: **wait for the M5 Max**. Experimental ([macOS requirements][macos59]).
