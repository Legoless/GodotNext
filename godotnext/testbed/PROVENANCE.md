# Testbed provenance

Budget: tracked size ≤ 50 MB. Current total: about 10 MB (about 0.4 MB
at creation; the #238 bakes added about 6 MB, almost all of it the
`VoxelGIData` embedded in `legacy_voxelgi.tscn`; #52 adds about 2 MB,
almost all of it the generated walker mesh. Measure with
`git ls-files godotnext/testbed | xargs du -ch` once tracked).

Every asset in this project is an original generated in this repository.
License for every row: MIT (same as the repository). Host for every row:
the Apple M5 Max. Date for every row: 2026-11-03.

All `.tscn` and `.json` rows are outputs of
`godot --headless --path godotnext/testbed --script res://generators/build_all.gd`,
seed `0x6E657874`. Do not edit them by hand; edit the generator and rerun.

The Dense City Blocks rows (#63) are the exception in size only: the
generator is tracked, but its output (about 2 GB across all variants,
including a 775 MB `.obj`) is generated on demand into the gitignored
`generated/dense_city/` folder and never tracked. The tracked additions
for #63 are the generator, its validator, `variants.cfg`, its README and
`expected.json` (counts, AABBs and the reference SHA-256 of every
output), all under `generators/dense_city/` and well under 1 MB in
total, so the 50 MB testbed budget is unaffected by the scene scale.
Regenerate with `res://generators/dense_city/dense_city_generator.gd`,
seed `1` (one run per variant; see its README).

The PN content rows (#148) follow the same rule: the generator is tracked
and its output is generated on demand into the gitignored
`generated/pn_content/` folder (about 116 MB for the three Foliage Field
variants, Displacement Cliff, Spline Road and Character Crowd; the crowd's
561k-triangle shared mesh is most of it). Every mesh, leaf texture,
MultiMesh transform and skinned body is procedural from the generator's
fixed streams; no third-party file is involved. Regenerate with
`godot --headless --path godotnext/testbed --script res://generators/build_pn.gd`
and run a scene through the harness with `--scene=res://generated/pn_content/<name>.tscn`.

overwrites it for a deliberate re-bake cycle; the README says how to
